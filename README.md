# 中国电信（泰国）有限公司 展示网站 

China Telecom (Thailand) Co., Ltd. — 中 / 英 / 泰三语企业展示网。

**线上地址**：https://ctth.chinatelecom-th.workers.dev

## 项目背景

海外公司对外展示长期依赖 PPT，在实际业务中存在几个难以回避的痛点：

- **多语言维护成本高**。同一份材料要维护中文、英文、泰文三个版本，内容一改就要改三份，版本极易不同步；泰文排版在 Office 中尤其容易出错。
- **展示场景受限**。PPT 依赖现场投屏或发送文件，客户无法随时自行查阅，转发后格式错乱、字体缺失是常态。
- **信息更新滞后**。业务板块调整、案例新增后，散落在各处的旧版 PPT 无法收回。

本网站将公司能力展示从"文件"迁移到"链接"：一个网址即可向泰国本地客户、中资出海客户与国际客户同时呈现，右上角一键切换中 / 英 / 泰，内容单点更新、全端同步。相比 PPT，网页更直观（动效流程图、地图导航、实景图库）、更易传播（微信 / 邮件发链接即可），并可通过后台查看访问情况。

## 内容结构

- **首页**：全球网络（CTG / 亚太）、核心业务、AI Token × 云间高速（动效流向图）、数据中心布线、智慧解决方案、服务保障、资质合作、联系我们（地址地图）
- **二级页**：
  - `connectivity.html` 国际网络与专线（低时延 / 波道 / IPLC / IEPL / MPLS VPN / EVPL）
  - `warehouse.html` 物流仓建设（八大强弱电分项 + 匿名案例）
  - `relocation.html` 机房搬迁（六大搬迁域 + 七步交付流程）
  - `about.html` 关于我们（公司简介 / 组织架构 / 备件库存）
- **后台**：`admin.html` 访问统计（口令进入，按小时 / 天分时段查看）

## 技术要点

- 纯静态站点：HTML + CSS + 原生 JavaScript，无构建步骤、无后端，任何静态托管均可部署。
- 三语 i18n：`data-i18n` 属性 + `js/i18n.js` 字典（三语各 358 键），localStorage 记忆语言偏好。
- 动效：IntersectionObserver 滚动显现、SVG 专线流光动画，均支持 `prefers-reduced-motion` 降级。
- 字体：系统字体栈（PingFang / 雅黑 / SF / Thonburi），不依赖任何字体 CDN，保证中国大陆访问速度。
- 统计：busuanzi（累计 PV/UV）+ CounterAPI（分时段计数，曼谷时区）。
- 部署：GitHub 推送后 Cloudflare Workers 自动构建上线（`wrangler.jsonc` 静态资产模式）。
